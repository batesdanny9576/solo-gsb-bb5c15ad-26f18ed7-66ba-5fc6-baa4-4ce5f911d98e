# 小批量标签拼版 Web 工具

输入纸张尺寸、页边距、多种标签的宽高与份数、裁切间距及是否允许旋转，
自动在每张纸上安排**互不重叠**的位置；放不下自动续页，并显示每种标签
实际排入数量。预览与可下载打印的 SVG 使用**同一套毫米坐标**，页边距与
间距在导出中完全一致。

支持**打印位置校准**：下载一张含横、纵两组基准刻线的测试页，100% 缩放
打印后量取各刻线在纸上的实际坐标，软件分别拟合 X / Y 方向的线性走纸误差；
下载及打印 SVG 时按误差的**逆变换**修正标签轮廓、裁切线与标注，让打印
结果落回设计位置。页面常规预览与 `/api/layout` 的坐标、数量保持原样。

支持**复用首张已贴过标签的纸张**：为第一张纸配置若干「占用区」
（左上角 x/y、宽、高，单位毫米），排版时作为障碍避让，新标签与其
保持设定的裁切间距；第一页放不下的份数自动续到后续空白页。预览中
占用区以灰色显示，下载 / 打印的 SVG 只包含新标签。

技术栈：Python 3.11 + FastAPI + 原生 HTML / CSS / JavaScript（无前端构建）。

## 一条命令启动

无需任何额外配置（不依赖数据库，仅需 Docker / Docker Compose）。
在项目根目录执行：

```bash
docker compose up --build
```

启动后浏览器访问：

- **http://localhost:8000**
- API 文档（Swagger）：**http://localhost:8000/docs**

端口通过 `docker-compose.yml` 固定映射 `8000:8000`；如本机 8000 端口
被占用，将其中左侧端口改为其它值（例如 `18000:8000`）后重新启动即可。
停止：`Ctrl+C`，或在另一个终端执行 `docker compose down`。

> 容器启动时会自动执行：安装依赖 → 初始化自检（排版、SVG 生成与
> 打印校准的冒烟测试）→ 启动 uvicorn。

## 功能说明

- **纸张**：内置 A4 / A5 / Letter 纵横预设，也可自定义任意毫米尺寸。
- **页边距**：上 / 右 / 下 / 左独立设置。
- **裁切间距**：水平、垂直分别设置；间距只出现在相邻标签之间，
  纸边不留多余半格。
- **裁切角线自动避让**：每个标签四角画外扩 1.5mm、单臂 3mm 的红色
  裁切角线，并对 8 段角线**逐段求可绘部分**——
  - 与本页其他标签轮廓相交的段裁到标签边缘为止，因此标签以 0mm
    间距紧贴时角线不会画进邻签；
  - 与首页「占用区」相交的段同样裁去（即使下载 / 打印的 SVG 不画
    占用区，角线也会正确避让）；
  - 落在纸张范围之外的段裁去，靠近纸边时不会画出纸面；
  - 裁切后残段短于 **0.5mm** 的整段省略，避免出现无意义的小短线；
  - 角线避让只改角线本身，**标签轮廓、排版数量与位置保持原样**。
  预览与下载 / 打印共用同一套裁切规则（均由后端 `POST /api/svg`
  生成）；应用走纸校准时，按逆变换**补偿后的坐标**判定邻签、首页
  占用区与纸边，避让结果与打印落位一致。
- **多种标签**：任意行数，每行设置名称、宽 (mm)、高 (mm)、份数、
  是否允许旋转 90°。
- **首张纸占用区（复用已贴纸的纸）**：
  - 在「首张纸占用区」中添加任意多个矩形，填写**左上角 X、左上角 Y、
    宽、高**（均为毫米，原点在纸张左上角），可随时编辑或删除；
  - 占用区必须完全在纸张范围内，越界（含负坐标、右边/下边超出纸张）
    会在前端与接口处给出明确错误，不生成排版；
  - 新标签把占用区当作障碍，无论从左、右、上、下接近，都至少保持
    设定的水平 / 垂直裁切间距；多个占用区可以重叠；
  - 第一页排不下的份数自动续到后续**空白页**，统计不丢失、不重复；
  - 占用区完全落在页边距区域内时不报错，仅提示“不影响排版”。
- **自动排版**：天际线（skyline）左下角装箱，标签位置互不重叠；
  当前页放不下自动续页；允许旋转时会尝试 90° 方向。
- **排入统计**：表格列出每种标签的需求数、实际排入数、旋转数、未排入数；
  单张标签超过可排区域时给出明确提示。
- **预览 / 导出同源**：浏览器预览和下载的 SVG 都由后端
  `POST /api/svg` 基于同一份排版结果生成，单位均为毫米。预览第一页以
  **灰色斜纹**绘制占用区；下载 / 打印的 SVG **只含新标签**，
  两者标签坐标完全一致。
- **导出**：支持「下载本页 SVG」「下载全部页」，以及按纸张精确尺寸
  排版的「打印全部页」（`@page size` 等于纸张毫米尺寸，无边距）。
- **打印位置校准（可选，只影响下载 / 打印）**：
  - 点击「① 打开 / 下载校准测试页」，按当前纸张尺寸生成测试页
    （5 条纵向实线 X1–X5 沿纸宽均布、5 条横向虚线 Y1–Y5 沿纸高均布，
    每条刻线旁标注设计坐标；页面标题提示 100% 缩放打印）；
  - 打印后用尺测量每条刻线的纸上位置：竖线量到纸张**左缘**、
    横线量到纸张**顶缘**（毫米），填入「实测」列，设计坐标由软件按
    当前纸张自动填入；
  - 点击「② 计算 X / Y 校准参数」，软件对两组数据分别做最小二乘
    拟合，得到线性走纸误差 `实测坐标 = 缩放 × 设计坐标 + 偏移`，
    并显示 X / Y 的缩放与偏移；
  - 勾选「应用校准补偿」后，「下载 SVG」「下载全部页」「打印全部页」
    的标签轮廓、裁切线、标注、页边距线等全部按逆变换
    `(设计 − 偏移) / 缩放` 逐点修正（线宽、字号不变），打印机再走
    一遍误差后内容恰好落回设计位置；裁切角线的避让判定也在补偿后
    的坐标空间进行——按补偿后的位置判断邻签与首页占用区、按补偿后
    的纸边上裁，不会在修正后的纸上侵入邻签或画出纸外；
  - **页面常规预览与 `/api/layout` 不携带校准参数**，坐标、页数与
    标签数量保持原样；
  - 出现以下情况时阻止校准导出并返回明确中文原因（HTTP 400）：
    1. **基准点重合**——设计坐标重复或实测坐标全部相同，无法拟合；
    2. **实测顺序颠倒**——实测值未随设计坐标递增（如从右往左 /
       从下往上读数或刻线对错位）；
    3. **补偿后内容超出纸张**——逆变换使任一标签的修正位置越出
       纸张边界，错误信息给出该标签与修正后坐标。

## 接口

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| GET  | `/health` | 健康检查 |
| POST | `/api/layout` | 提交参数（含首张纸 `occupied_zones`），返回分页排版结果（毫米坐标）；**不涉及校准，坐标/数量恒为原始结果** |
| POST | `/api/svg` | 提交参数 + 页码 + 显示开关 + 可选 `calibration` 校准数据，返回该页 SVG；提供 `calibration` 时按逆变换修正坐标 |
| GET  | `/api/calibration/page?page_width=&page_height=` | 下载校准测试页 SVG（横、纵两组基准刻线） |
| GET  | `/api/calibration/marks?page_width=&page_height=` | 返回测试页两组基准刻线的设计坐标 JSON（界面自动填表） |
| POST | `/api/calibration/solve` | 提交两组「设计 / 实测」刻线坐标，返回 X / Y 拟合结果 `scale`、`offset` |

`/api/svg` 在服务端重新计算同一份排版，保证导出坐标与预览一致。
其 `show_occupied` 开关仅预览时为 `true`（第一页灰色绘制占用区）；
下载 / 打印时为 `false`，SVG 中只包含新标签。界面的常规预览请求
**不带** `calibration`，仅「下载 / 打印」动作携带。
API 文档（Swagger）：http://localhost:8000/docs

### 校准数据格式

`/api/svg` 的 `calibration` 字段与 `/api/calibration/solve` 的请求体相同：

```json
{
  "x_lines": [
    {"design": 21.0, "measured": 21.3},
    {"design": 63.0, "measured": 63.2}
  ],
  "y_lines": [
    {"design": 29.7, "measured": 30.0},
    {"design": 89.1, "measured": 89.4}
  ]
}
```

每组至少 2 条；`x_lines` 为纵向刻线（校准 X），`y_lines` 为横向刻线
（校准 Y）。拟合结果形如
`{"x": {"scale": 1.0012, "offset": 0.08}, "y": {"scale": 0.998, "offset": 0.2}}`。
基准点重合、实测顺序颠倒由 solve 与 svg 两个接口共同拦截；
补偿后内容超出纸张仅在 `/api/svg` 拦截（需结合具体排版）。

### 请求示例

```json
{
  "page_width": 210,
  "page_height": 297,
  "margin_top": 8,
  "margin_right": 8,
  "margin_bottom": 8,
  "margin_left": 8,
  "gap_x": 2,
  "gap_y": 2,
  "labels": [
    {"name": "品名标签", "width": 60, "height": 30, "count": 20, "allow_rotate": true},
    {"name": "箱贴", "width": 100, "height": 70, "count": 6, "allow_rotate": false}
  ],
  "occupied_zones": [
    {"x": 48, "y": 48, "width": 100, "height": 100}
  ]
}
```

`occupied_zones` 为可选数组，仅作用于第一页；每项的 `x` / `y` 为
占用区左上角相对纸张左上角的坐标，`width` / `height` 为其尺寸。
越界（`x + width > page_width`、`y + height > page_height` 或坐标为负）
返回 HTTP 400 及明确中文错误，例如：

```text
占用区 1越界：x(120.0) + 宽(100.0) = 220.0mm 超过纸张宽度 210.0mm。
```

## 本地开发（不使用 Docker）

```bash
pip install -r requirements.txt
python -m app.bootstrap          # 可选：初始化自检
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
